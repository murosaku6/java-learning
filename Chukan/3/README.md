# 成績管理システム

## 概要

Spring Bootを用いて開発している学校向けの成績管理システムです。

学生・科目・成績を管理し、成績の登録・編集・削除だけでなく、平均点や最高点・最低点などの統計情報、学生・科目による検索、学生別ランキングの表示などを行うことができます。

本システムはMVCモデルを採用し、Spring Boot・Thymeleafを用いたWebアプリケーションとして開発しています。

---

# 開発目的

Javaのオブジェクト指向を活かした設計を実践するとともに、Spring Bootを利用したWebアプリケーション開発を経験することを目的としています。

また、Controller・Service・Modelの役割を意識した設計や、実務を想定した保守性・可読性の高いコードを書くことを目標としています。

さらに、開発初期ではArrayListを利用してデータを管理し、将来的にMySQLへ移行できる構成を意識して開発しています。

# システム構成

```text
Controller
    ↓
Service
    ↓
Model
```

MVCアーキテクチャを採用しています。

Controllerでは画面からのリクエストを受け取り、Serviceで業務ロジックを処理し、Modelで学生・科目・成績などのデータを管理しています。

評価は以下の基準で自動的に設定されます。

| 点数 | 評価 |

# 検索機能

成績一覧画面から検索条件を指定して成績を絞り込むことができます。

- 学生検索
- 科目検索
- 学生＋科目による複合検索
- 検索条件のクリア

例：

```text
学生：山田 太郎
科目：数学
        ↓
山田 太郎の数学の成績のみ表示
```

---

# 統計機能

成績データを集計し、以下の統計情報を表示できます。

- 全体平均点
- 最高点
- 最低点
- 学生別平均点
- 科目別平均点

学生別・科目別に成績を集計することで、単純な成績一覧だけではなく、データを分析できるようにしています。

---

# ランキング機能

現在、学生ごとの平均点を利用したランキング機能を実装しています。

- 学生平均点ランキング
- 平均点の高い順に自動ソート
- 順位の自動表示
- 学生名・平均点の表示

例：

```text
順位    学生名        平均点
1       山田 太郎     91.5
2       佐藤 花子     76.0
```
